# Веб-приложение для прогнозов погоды outside-project

## Обзор

Это веб-приложение на Flask, которое предоставляет информацию о прогнозе погоды для запрашиваемого города. 
Пользователи могут ввести название города и получить актуальные данные о текущей погоде и прогнозе.

## Возможности

* Поиск погоды по названию города
* Отображение текущей погоды
* Отображение прогноза на ближайшие дни

## Технологии

* Flask
* Flask-Login (для управления аутентификацией пользователей)
* Flask-Mail (для отправки email подтверждений)
* Jinja2 (для шаблонов)
* Bootstrap (для стилизации)
* PostgreSQL (в качестве основной базы данных)
* SQLAlchemy (в качестве ORM)
* python-weather (для API запросов к погодному сервису)
* Docker (для контейнеризации)

## Установка

### Предварительные требования

* Python 3.12+
* Docker (опционально)

## Настройка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/classytoast/outside-project.git
   cd outside-project
   ```

2. Создайте виртуальное окружение:

    ```
    python -m venv venv
    source venv/bin/activate  # Для Windows: `venv\Scripts\activate`
    ```

3. Установите зависимости:

    ```
    pip install -r requirements.txt
    ```

4. Запустите приложение:

    ```
    python src/main.py
    ```

## Запуск с Docker

1. Соберите и запустите контейнер:

    ```
    docker up --build
    ```

2. Приложение будет доступно по адресу http://localhost:5000
